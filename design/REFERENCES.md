# Design references (for the website later)

## Refero Styles
- Library: https://styles.refero.design/ — 2,000+ website design systems; each has colors,
  typography, spacing, components and an AI-readable DESIGN.md.
- Connect to an AI tool (Claude Code etc.): https://refero.design/mcp — lets the AI look up
  styles live while building, instead of copying them here.
- Use them for **ideas** (layout, spacing, type scale, how pricing/feature sections are laid
  out). Don't copy another company's look one-to-one — the website should look like CareMile.
